# Question 6: Critical Path and Minimum Project Duration

**Topics:** Project Scheduling, Task Dependencies, Critical Path, Parallelism

## 📝 Question

> A project has three tasks: Task A takes two hours and must be finished before the other two tasks. Task B takes one hour and Task C takes three hours, and both can be done after A. Two people can work at the same time. What is the minimum total time?

## 🔢 Options

**Option 1:** 4 hours

**Option 2:** 3 hours

**Option 3:** 6 hours

**Option 4:** 5 hours

## 💡 About this question

This is a simple **scheduling-with-dependencies** problem that tests the concept of the **critical path**.

Given: A (2 h) must finish first; after it, B (1 h) and C (3 h) are independent of each other and, since we have two people, can run **in parallel**. The usual assumption is that one person does each task and splitting a task between two people does not speed it up.

Calculation: stage one is A = 2 h. In stage two B and C run in parallel, so its duration is the longer of the two: `max(1, 3) = 3`. Total: `2 + 3 = 5` hours.

## 🔍 Detailed review of every option

### Option 1 — ❌ Incorrect

> 4 hours

**Incorrect.** 4 hours is not consistent with the problem's constraints. Even if B and C are perfectly parallel, C alone takes 3 hours and must start after A's 2 hours; so less than 5 hours is impossible. (This number usually comes from a miscalculation or from splitting tasks between two people, which is not an assumption of the problem.)

### Option 2 — ❌ Incorrect

> 3 hours

**Incorrect.** 3 hours is just C's duration and ignores A's dependency. C can start only after A finishes, so A's 2 hours must also be added to the total.

### Option 3 — ❌ Incorrect

> 6 hours

**Incorrect.** 6 hours is the plain sum of all three tasks (`2+1+3`), i.e. it assumes only one person works. We have two people, and B and C can run at the same time, so the total is less than 6 hours.

### Option 4 — ✅ Correct

> 5 hours

**Correct.** The critical path is `A → C`: `2 + 3 = 5` hours. B runs in parallel during that time (one hour of C's three) and does not add to the total.

## ✅ Correct answer

**Option 4**

> 5 hours

## 🎯 Why it is correct

The total project time equals the length of the **longest dependency chain**: `A → C = 5` hours. Task B is not on the critical path and runs in parallel, so it does not extend the duration.

## 📌 Key takeaway

Don't compute project time as the sum of all tasks; compute the length of the critical path (the longest dependent chain).
