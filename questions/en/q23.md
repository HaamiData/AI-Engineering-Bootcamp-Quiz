# Question 23: The Mislabeled Boxes Puzzle

**Topics:** Logical Reasoning, Elimination of Cases, Puzzle

## 📝 Question

> We have three boxes labeled ‘apples’, ‘oranges’ and ‘apples and oranges’. We know all three labels are wrong. From the box labeled ‘apples and oranges’ we take out one fruit and it is an apple. What does the box labeled ‘oranges’ contain?

## 🔢 Options

**Option 1:** Only apples

**Option 2:** Only oranges

**Option 3:** A mix of apples and oranges

**Option 4:** It cannot be determined from this information

## 💡 About this question

A classic logic puzzle. The key is that **all labels are wrong**, so each label restricts the possible contents.

Step-by-step reasoning:

1. The "apples and oranges" box has a wrong label, so it is **not mixed**. The fruit drawn was an apple, so this box contains **only apples**.
2. Now the "oranges" box: its label is wrong, so it is not "only oranges." It is not "only apples" either, because the only-apples box is the previous one. So it must be **mixed**.
3. Consequently, the "apples" box contains only oranges.

## 🔍 Detailed review of every option

### Option 1 — ❌ Incorrect

> Only apples

**Incorrect.** "Only apples" is the box labeled "apples and oranges" (since an apple came out of it and its label is wrong). Each box has different contents, so the "oranges" box cannot be “only apples.”

### Option 2 — ❌ Incorrect

> Only oranges

**Incorrect.** This box's label is "oranges," and we know all labels are wrong; so this box cannot contain only oranges.

### Option 3 — ✅ Correct

> A mix of apples and oranges

**Correct.** Once it is established that the "apples and oranges" box holds only apples, only the mixed case remains for the "oranges" box (not "only oranges" because of its wrong label, and not "only apples" because that is already taken).

### Option 4 — ❌ Incorrect

> It cannot be determined from this information

**Incorrect.** The information is sufficient. With the assumption "all labels are wrong" and a single draw from the "apples and oranges" box, the contents of all three boxes are uniquely determined.

## ✅ Correct answer

**Option 3**

> A mix of apples and oranges

## 🎯 Why it is correct

With the condition "all labels are wrong" and a single draw, the only consistent case for the "oranges" box is that it is mixed.

## 📌 Key takeaway

In logic puzzles, use definite constraints (like “all are wrong”) to eliminate cases, and cross out the cases already taken.
