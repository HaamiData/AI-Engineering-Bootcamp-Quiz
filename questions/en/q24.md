# Question 24: Reviewing the Evaluation Method of a Spam Classifier

**Topics:** Imbalanced Data, Precision/Recall/F1, Leakage, Train/Validation/Test

## 📝 Question

> A team asked an AI assistant to review the evaluation method of a spam email classifier. The assistant's answer: “95% of emails are non-spam, so instead of accuracy I used precision, recall and F1 for the spam class. I fit the TF-IDF vectorizer only on the training data and only applied transform on validation and test. I tuned the decision threshold on the validation set and evaluated the final model only once at the end on the test set. Result: precision 0.91 and recall 0.87.” Which statement about this answer is correct?

## 🔢 Options

**Option 1:** The threshold should have been tuned on the test set to obtain the best possible precision and recall on the final data.

**Option 2:** TF-IDF should not be fit only on train and should be fit on the entire data so that the vocabulary of validation and test is also covered.

**Option 3:** Accuracy is the only valid metric for this problem and should be reported instead of precision and recall.

**Option 4:** From a methodological standpoint no specific problem is seen; the choice of metrics, prevention of information leakage and one-time use of the test set are correct.

## 💡 About this question

Unlike several earlier questions, this one has a **reverse trap**: sometimes the assistant's answer is methodologically correct and we should avoid "nitpicking for nothing." We check four methodological points one by one:

1. **Metric:** the data is imbalanced (95% non-spam); a model that calls everything non-spam gets 95% accuracy. So precision/recall/F1 for the spam class is the right choice.
2. **TF-IDF:** it should be fit on train only, with only transform applied on validation/test, so that no information (vocabulary and IDF) leaks from the evaluation data.
3. **Threshold:** it should be tuned on validation, not on test.
4. **Test:** it should be used only once at the end.

All four are respected in the assistant's answer.

## 🔍 Detailed review of every option

### Option 1 — ❌ Incorrect

> The threshold should have been tuned on the test set to obtain the best possible precision and recall on the final data.

**Incorrect.** Tuning the threshold on the test set means selecting based on the test set and leaking information; the final number becomes optimistic. The threshold should be tuned on validation and the test set kept for a single final evaluation, which is exactly what the assistant did.

### Option 2 — ❌ Incorrect

> TF-IDF should not be fit only on train and should be fit on the entire data so that the vocabulary of validation and test is also covered.

**Incorrect.** Fitting TF-IDF on the whole dataset lets statistics from validation and test (vocabulary and IDF weights) enter the training stage, i.e. information leakage. In real deployment, future emails are also not seen at training time; unfamiliar words are natural and should be simulated the same way.

### Option 3 — ❌ Incorrect

> Accuracy is the only valid metric for this problem and should be reported instead of precision and recall.

**Incorrect.** Accuracy is misleading on imbalanced data: a classifier that calls every email non-spam gets 95% accuracy but catches no spam. The claim of "the only valid metric" is false; precision, recall and F1 are more suitable for the minority class.

### Option 4 — ✅ Correct

> From a methodological standpoint no specific problem is seen; the choice of metrics, prevention of information leakage and one-time use of the test set are correct.

**Correct.** The choice of metrics (precision/recall/F1 because of imbalance), leakage prevention (fit only on train), tuning the threshold on validation and one-time use of the test set are all correct. So no specific methodological flaw is seen.

## ✅ Correct answer

**Option 4**

> From a methodological standpoint no specific problem is seen; the choice of metrics, prevention of information leakage and one-time use of the test set are correct.

## 🎯 Why it is correct

All four methodological decisions of the assistant are standard and correct. The other options either introduce leakage (1 and 2) or propose an unsuitable metric (3).

## 📌 Key takeaway

The standard pattern: a metric suited to imbalance, preprocessing fit on train only, hyperparameters/threshold tuned on validation, and a single final evaluation on test.
